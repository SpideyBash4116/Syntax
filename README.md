## Overview

`Syntax` is a custom terminal prototype built on the `.NET 8.0` framework. It provides a simplified command-line interface for basic file system navigation and system output.

## Available Commands

To see a list of commands within the application, type `help`.

| Command | Description |
| :--- | :--- |
| `help` | Show the help menu. |
| `exit` | Exit the terminal. |
| `clear` | Clear the screen. |
| `echo <text>` | Print text to the console. |
| `cd <path>` | Change the current directory. |
| `dir` | List files and directories in the current path. |
| `beep` | Creates a beep noise. (coming soon) |
